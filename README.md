# Python Exceptions Reference : Exceptions_Python.html

A clean, interactive web app that displays Python's built-in exceptions in a collapsible tree. Click any exception to see a simple explanation and a code example. Includes smart search (try "encode" or "file") and highlights commonly used exceptions with a ★ star. Built with pure HTML/CSS/JS — no dependencies, just open `index.html` in your browser.

Made for Python learners and developers who want a quick, beautiful reference without leaving their browser.
